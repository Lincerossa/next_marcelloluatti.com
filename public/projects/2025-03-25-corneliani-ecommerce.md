  We managed to use part of the previous stack we have used in the FAI
  project[](https://www.marcelloluatti.com/projects/fai), which involved
  Next.js, React, Redux, Storybook and Jest for testing purposes.


  Compared to the previous project, we built a GraphQL layer in order to solve issue performances (for example the payload server-client) and other side effects while the application was scaling.


  This layer had the task of handling the communication between the frontend and both Wordpress (for the CMS side) and Magento (the e- commerce side). The project is based on AWS.
